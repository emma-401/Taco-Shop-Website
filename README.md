
## Little Taco Shop Website 🌮

A multi-page responsive website for a fictional restaurant, Little Taco Shop, built using HTML, CSS, and JavaScript.
This project demonstrates structured layout design, modern CSS techniques, responsive behavior, and interactive elements.

## Project Overview 🌟

This website was created as part of a front-end learning project inspired by Dave Gray’s CSS course on freeCodeCamp.
It showcases how to transform semantic HTML into a visually appealing, functional website using CSS and basic JavaScript.

## Features 🧩

✨ Multi-page website structure
✨ Responsive layout for different screen sizes
✨ Dark mode support using CSS variables
✨ Sticky header and footer
✨ Navigation between pages
✨ Menu section with styled table layout
✨ Contact form interface
✨ Animated hero section
✨ Clean BEM-style class naming
✨ Smooth scrolling behavior

## Pages Included 📄

1. Home / Landing Page 🏠 (index.html)

2. Hours Page ⏰ (hours.html)

3. About Page 📖 (about.html)

4. Contact Page 📞 (contact.html)

# Technologies Used 🛠️

1. HTML5

2. CSS3 (Custom Properties / Variables)

3. JavaScript (Basic Interactivity)

4. Google Fonts

# Design Highlights 🎨

-- CSS Reset for consistent styling

-- Root variables for theme management

-- Light mode (default) and dark mode support

-- Flexbox and Grid layout techniques

-- BEM methodology for organized CSS structure

-- Responsive font sizing using clamp()
